# ИП Лащ Н. В. — натяжные потолки, Молодечно

Потолки любой сложности: эконом и премиум, сложные профили, световые линии. Бесплатный замер с
образцами, договор с гарантией, цена до конца работ. Телефон +375 33 992-21-15.

**Живой сайт:** https://romjjjke.github.io/lash-potolki/

## Что внутри

- Герой с ведомостью: замер, цена, монтаж — три строки вместо обещаний.
- Гид по шести комнатам с липким индексом, который подсвечивается по скроллу: что важно, какие
  полотна уместны, что учесть по свету и профилю.
- Пин-сцена «образцы»: четыре типа полотна (мат, сатин, глянец, ткань), отблеск меняется по скроллу,
  справа — спецификация и «где уместен». На мобильном пин отключается, образцы переключаются кнопками.
- Порядок из трёх шагов, блок «обещание» с фиксацией суммы, FAQ на `<details>`, форма заявки в WhatsApp.

## Стек

React + Vite + TypeScript, GSAP + ScrollTrigger (лениво, только для сцены образцов), Lenis.
Шрифты самохостингом: Spectral 500/600 + Rubik 400/500, 86 KB на 8 файлов, метрические фолбэки
(`size-adjust` 105,6% и 104%). Иллюстраций и фотографий нет: поверхности собраны на CSS-градиентах.

## Ограничения

Цен нет: заказчик дал только «адекватные цены», поэтому на сайте ни одной выдуманной цифры — вместо
прайса состав сметы и правило «сумма фиксируется в договоре». Срок гарантии не указан, потому что
заказчик его не называл: в тексте только «по договору». Фотографий работ не было, поэтому сайт
целиком типографический, а образцы полотна собраны на CSS: это честная имитация отблеска, а не
снимок реального материала.
